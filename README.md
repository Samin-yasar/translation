# Translations

Independent Bengali translations of digital security and privacy guides.
Each project lives in its own folder with its own README and license.
Hosted on GitHub Pages at https://translation.samin-yasar.dev.

## Active projects

- [ssd/](./ssd/) — Bengali translations of EFF Surveillance Self-Defense guides

## Site philosophy

- clear catalog structure
- consistent translation glossary
- source tracking for every guide
- guide-level metadata and audit trail
- clean static-site presentation inspired by the SSD reference site
